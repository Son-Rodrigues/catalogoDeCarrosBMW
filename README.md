# 🚘 Catálogo de Carros BMW

> Catálogo de veículos BMW desenvolvido como projeto de estudo em desenvolvimento web.

## 📌 Sobre o projeto

Este projeto consiste em uma página de catálogo de veículos da BMW, desenvolvida para praticar a criação de interfaces web e a organização de informações em uma aplicação visual.

A proposta é apresentar diferentes modelos de veículos de forma organizada, utilizando uma interface inspirada no estilo visual da marca.

O projeto também foi utilizado para praticar conceitos de estruturação de páginas, estilização, responsividade e organização de código.

---

## ✨ Funcionalidades

- 🚘 Apresentação de veículos BMW
- 🖼️ Exibição de imagens dos modelos
- 📋 Informações dos veículos
- 🎨 Interface inspirada na identidade visual da BMW
- 📱 Layout responsivo
- 🧩 Organização dos conteúdos em seções
- 🖥️ Interface desenvolvida para diferentes tamanhos de tela

## 🎯 Objetivo do projeto

O principal objetivo deste projeto foi praticar desenvolvimento frontend através da criação de uma interface de catálogo.

A escolha de um catálogo de veículos permitiu trabalhar com diferentes tipos de conteúdo visual e estruturar as informações de forma que o usuário consiga navegar pelos modelos apresentados.
